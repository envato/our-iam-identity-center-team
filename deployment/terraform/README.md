# Prequisites
- You will need to have access into the Envato TEAM Test - 010928195081 aws account for the staging environment. The staging account is in the seperate AWS organization https://d-9067eccd8b.awsapps.com/start
- You will need to have access into the Access Management - Production - 221082199185 aws account for the prod environment
- To deploy with Terraform, you’ll need to export the Cognito client secret used by the `machine_auth` app client. The command below will automatically find the correct user pool and client, fetch the secret, and set it as an environment variable so Terraform can access it. This value is sensitive, so make sure it’s handled securely.
  Assuming you have a shell with appropriate AWS credentials:
- You will also need to have a github access token available that can read the team application repository (our-iam-identity-center-team - in example below it is stored in the keychain in an entry called team-app-deployment-github-token), it also needs to set webhooks, so for PAT it needs to be generated by someone with Admin rights to the repository
```
export HISTCONTROL=ignoreboth  # Space at start of next lines are intentional
  export userpool=$(aws cognito-idp list-user-pools --max-results 10 --query 'UserPools[?contains(Name,`team`)].Id' --output text)
  export clientid=$(aws cognito-idp list-user-pool-clients --user-pool-id ${userpool}  --query 'UserPoolClients[?ClientName==`machine_auth`].ClientId' --output text)
  export userpool=$(aws cognito-idp list-user-pools --max-results 10 --query 'UserPools[?contains(Name,`team`)].Id' --output text)
  export TF_VAR_team_client_secret=$(aws cognito-idp describe-user-pool-client --client-id ${clientid} --user-pool-id=${userpool} --query  UserPoolClient.ClientSecret --output text)
  export TF_VAR_github_access_token=$(security find-internet-password -w -a team-app-deployment-github-token)
```

Now you're ready to:
